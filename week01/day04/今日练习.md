## 01｜字典成绩查询 ⭐

实现：

```python

    pass
```

输入：

```python

    "Tom": 78,
    "Alice": 95,
    "Bob": 88
}
```

要求：
- 如果 `name` 存在，返回对应成绩。
- 如果不存在，返回 `-1`。


```text

```

## 04｜共同技能 ⭐⭐⭐

实现：

```python

    pass
```

输入：

```python
a = {"Python", "Git", "SQL", "Docker"}
b = {"Python", "Git", "Java"}
```

返回：

```python
{"Python", "Git"}
```

再分别得到：
- 两人所有技能（并集）
- 只属于 `a` 的技能（差集）
- 只属于其中一人的技能（对称差）

练习点：`& | - ^`。
