## 01｜自己实现列表求和

写：

```python
def list_sum(nums):
    pass
```

要求计算列表所有数字之和。

测试：

```python
print(list_sum([1, 2, 3, 4, 5]))
print(list_sum([10, -3, 2]))
print(list_sum([]))
```

预期：

```text
15
9
0
```

限制：不使用内置 `sum()`。

```python
sum()
```

第一次手写：

```python
def list_sum(nums):
    len_sum=len(list_sum)
    sum=0
    for i in range(len_sum):
        sum+=list_sum[i-1]
    return sum
print(list_sum([1,2,3,4,5]))
```

无法运行,错误原因：TypeError: object of type 'function' has no len()
发现原因:1.list_sum是函数名，我要len的是传的参数
2.这里的 `range(len_sum)` 从 0 开始；`for` 本身不规定起始值。

改正后的：

```python
def list_sum(nums):
    len_sum=len(nums)#len的是传来的参数 不是函数名,list_sum是函数名
    sum=0
    for i in range(len_sum):#这里 range(len_sum) 从0开始
        sum+=nums[i]
    return sum
print(list_sum([1,2,3,4,5]))
print(list_sum([10,-3,2]))
print(list_sum([]))
```

创新思路：在python里for可以直接遍历列表元素
记一个非常常用的模式：

```python
total = 0
for x in xxx:
    total += x
```

这就是**累加器 accumulator**。
刚刚的题就是：

```python
def list_sum(nums):
    total=0 # 要求提前定义total 不然就是 ?+num 会报错
    for num in nums:
        total=total+num # 可以写成total+=num
    return total
print(list_sum([1,2,3,4,5]))
print(list_sum([10,-3,2]))
print(list_sum([]))
```

## 02｜筛选偶数（原题：输出奇偶）

```python
def get_even(nums):
    pass
```

目标：

```python
get_even([1,2,3,4,5,6])
```

返回：

```text
[2,4,6]
```
第一次尝试：

```python
def get_even(nums):
    a=[]
    for num in nums:
        if num%2==0:
            a=a.append[num]
get_even([1,2,3,4,5,6])
```

报错：TypeError: 'builtin_function_or_method' object is not subscriptable
错误原因：1.append是函数要用(),[]是取索引
2.`a = a.append(num)` 语法合法，但会把返回值 `None` 赋给 a；只写 `a.append(num)` 就能修改列表。
3.没有返回值，到时候没有输出了

第二次：

```python
def get_even(nums):
    a=[]
    for num in nums:
        if num%2==0:
            a.append(num)
    print(a)
get_even([1,2,3,4,5,6])
```

逻辑运行正确，但是函数体没有返回值，不够标准，后续这个结果不能拿去用，所以最好还是用return a，然后测试用print输出

## 03｜查找目标元素

实现函数：

```python
def find_target(nums, target):
    pass
```

要求：

> 在列表 `nums` 中查找 `target` 第一次出现的位置。

如果找到，返回它的**下标**。

如果没找到，返回：

```text
-1
```

测试代码：

```python
print(find_target([10, 20, 30, 40], 30))
print(find_target([5, 8, 5, 9], 5))
print(find_target([1, 2, 3], 10))
```

预期输出：

```text
2
0
-1
```

第一次：

```python
def find_target(nums,target):
    len_nums=len(nums)
    for i in range(len_nums):
        if target==nums[i]:
            return i
    return -1
print(find_target([10,20,30,40],30))
print(find_target([5,8,5,9],5))
print(find_target([1,2,3],10)) # 测试结果正确
```

评价：可以以后简化成：

```python
for i in range(len(nums)):
```

不用单独先写：

```python
len_nums = len(nums)
```

但你现在这样写也完全没问题，更直观。

## 04｜列表去重

实现：

```python
def remove_duplicates(nums):
    pass
```

要求：

> 去掉列表中的重复元素，但保留第一次出现的顺序。

测试：

```python
print(remove_duplicates([1, 2, 2, 3, 1, 4]))
print(remove_duplicates([5, 5, 5]))
print(remove_duplicates([]))
```

预期：

```text
[1, 2, 3, 4]
[5]
[]
```

限制：不使用 `set()`。

```python
set()
```
第一次：

```python
def remove_duplicates(nums):
    a=[]
    len_a=len(a)
    for num in nums:
        for i in range(len_a):
            if num==a[i]:
                break
            else:
                continue
    a.append(num)
    return a
print(remove_duplicates([1,2,2,3,1,4]))
```

错误原因:1.len_a应该一直在变化，但是我给固定了
2.还没搞清楚append应该放在哪层循环
3.今天学了更合适的方法in 和 not in

第二次尝试自己的方法还是没做出来，在看了提示后发现要加一个判断值True False
```python
def remove_duplicates(nums):
    hahas=[]
    for num in nums:
        found=False
        for haha in hahas:
            if num==haha:
                found=True
                break
        if found==False:
            hahas.append(num)
    return hahas
print(remove_duplicates([1,2,2,3,1,4]))
```

就看看就行，有这个思路，但是python提供了更简单的方法

```python
def remove_duplicates(nums):
    hahas=[]
    for num in nums:
            if num not in hahas:
                  hahas.append(num)
    return hahas
print(remove_duplicates([1,2,2,3,1,4]))
```

```python
def second_largest(nums):
    len_nums=len(nums)
    for i in range(len_nums):
        if nums[i]>nums[i]:
            nums[i],nums[i+1]=nums[i+1],nums[i]
```

虽然结果对了，但是我发现这个最后一个我是碰出来的，好像逻辑上不太对。 
评价：哈哈，连i+1都忘写了，正好例子全凑上了。设计冒泡排序，我正好学一下。
冒泡排序搞明白了，但是这题不适合，因为有重复的情况，所有还是用python写法

```python
def second_largest(nums):
    a=[]
    for num in nums:
        if num not in a:
            a.append(num)
    a.sort()
    return a[-2]
print(second_largest([10, 5, 8, 20, 15]))
print(second_largest([3, 1, 2]))
print(second_largest([100, 50, 80, 90]))
print(second_largest([10, 20, 20, 15]))
```
