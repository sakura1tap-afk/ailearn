# Python 函数

> [!abstract] 本篇重点
> **`def` 定义函数，`return` 返回结果；`print()` 只负责显示。**

## 什么是函数

函数是一个命名的代码块，用于执行任务或返回一个值。

## 为什么需要 Python 中的函数

有时，你需要在程序中多次执行同一任务。而且你也不想把同样任务的代码复制到各个地方。

为此，你需要将代码包裹在函数中，并在需要时使用该函数执行任务。

## 定义 Python 函数

### 1）函数定义

函数定义以关键字 `def` 和函数名开头，随后是括号中的参数列表。
函数定义总是以冒号（`:`）结尾。
## 摘要

- Python 函数是一个可重复使用的命名代码块，用于执行任务或返回一个值。
- 使用 `def` 定义函数；函数包含定义行和缩进的函数体。
- 函数可以有零个或多个参数；调用时必须满足必填参数，带默认值的参数可以省略。
- 函数可以执行任务或返回一个值。使用该语句返回函数的值。`return`
