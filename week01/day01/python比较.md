## Python 比较运算符介绍

在编程中，你通常想比较一个值和另一个值。为此，你需要使用比较运算符。

Python 有六个比较运算符，具体如下：

- 小于 （`<` )
- 小于或等于（`<=`)
- 大于 （`>`)
- 大于或等于 （`>=`)
- 等于 （`==` )
- 不等于 （`!=` )

这些比较运算符比较两个值，返回一个[布尔](https://www.pythontutorial.net/python-basics/python-boolean/)值True或 False。

你可以用这些比较运算符来比较[数字](https://www.pythontutorial.net/python-basics/python-numbers/)和[字符串](https://www.pythontutorial.net/python-basics/python-string/)。

## 摘要

- 比较运算符比较两个值，返回 `True` 或 `False`。
- 六个比较运算符：小于 `<`、小于等于 `<=`、大于 `>`、大于等于 `>=`、等于 `==`、不等于 `!=`。
