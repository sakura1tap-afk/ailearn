# Python 类型转换

> [!abstract] 本篇重点
> **`input()` 返回字符串；计算前按需要用 `int()` 或 `float()` 转换。**
>
> 前置知识：[[python数字|Python 数字]]、[[python字符串|Python 字符串]]、[[python布尔|Python 布尔值与真值判断]]
> 所属知识链：[[00 Python学习导航]] · [[01 Python知识图谱]]

要将表示整数的字符串转换为整数，可以使用 `int()`。

以下示例使用该函数将输入字符串转换为数字：`int()`

```python
price = input('Enter the price ($):')
tax = input('Enter the tax rate (%):')

tax_amount = int(price) * int(tax) / 100
print(f'The tax amount is ${tax_amount}')
```

## 其他类型转换函数

除了 `int(str)`，Python 还支持以下类型转换函数：

- `float(str)`– 将字符串转换为[浮点数](https://www.pythontutorial.net/advanced-python/python-float/)。
- `bool(val)`– 将一个值转换为[布尔](https://www.pythontutorial.net/python-basics/python-boolean/)值，即 `True` 或 `False`。
- `str(val)`– 返回一个值的字符串表示。

## 获取某个值的类型

要获取某个值的类型，使用 `type(value)`。

## 摘要

- 使用 `input()`从用户那里获取输入字符串。
- 使用 `int()`、`float()`、`bool()`、`str(value)` 等函数进行类型转换。
- 使用 `type()`获取值的类型。
