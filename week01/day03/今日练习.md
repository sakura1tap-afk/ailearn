### 02｜偶数平方

实现：

```
def even_square(nums):
    pass
```

要求：

> 从列表里找出所有偶数，并把这些偶数平方后放进一个新列表返回。

例如：

```
print(even_square([1, 2, 3, 4, 5, 6]))
```

预期输出：

```
[4, 16, 36]
```
第一遍尝试：def even_square(nums):

   for num in nums:

      if num%2==0:

         new_num.append(num)

         return new_num*2

  
第二遍尝试：def even_square(nums):
def even_square(nums):

   new_num=[]

   for num in nums:

      if num%2==0:

         new_num.append(num*num)

   return new_num
print(even_square([1,2,3,4,5,6]))
print(even_square([1,3,5]))
print(even_square([-2,-1,0,2]))
num*num可以写成num**2指数嘛，然后今天学的是列表推导式，所以用列表推导式再写一遍。

def even_square(nums):

   new_nums[num**2 for num in nums if num%2==0]

   return new_nums 
   第一次写函数体，提示SyntaxError: invalid syntax
   ai告诉我了
   你这里差的是 **赋值符号 `=`**。

你现在写的是：

```
new_nums[num**2 for num in nums if num%2==0]
```

Python 会把它理解成：

> 对 `new_nums` 做下标/索引操作

但你真正想表达的是：

> 把这个列表推导式生成的新列表，赋值给 `new_nums`

还可以写的更简单，直接把这个推导体写到return里
def even_square(nums):

   return [num**2 for num in nums if num%2==0]
   真神奇
   你可以把列表推导式记成这个模板：

```
[结果 for 元素 in 可迭代对象 if 条件]
```

### 05｜LeetCode 283：移动零

下一题我们别继续堆 `lambda` 了，换回更直观的逻辑题。

实现：

```
def move_zeroes(nums):
    pass
```

要求：

> 把所有 `0` 移到列表末尾，其他数字保持原来的相对顺序。

例如：

```
print(move_zeroes([0, 1, 0, 3, 12]))
```

预期：

```
[1, 3, 12, 0, 0]
```

第一次：def move_zeroes(nums):

    for num in nums:

        if num==0:

            nums.remove(num)

            nums.append(0)

    return nums

  

print(move_zeroes([0, 1, 0, 3, 12]))用自己的小巧思写的，感觉没有用到学的知识，迭代器啊，元组啊，列表啊啥的。
第一次思路： 遍历列表，遇到0就 remove(0)，然后 append(0)。 优点： 写法简单，可以原地修改列表。 缺点： remove需要查找并移动元素，效率较低。 遍历过程中修改列表一般需要谨慎，但这个题的特殊结构下可以工作。 后续： 学习双指针后再优化。

你可以重新设计成：

```
准备一个新列表
↓
遍历 nums
↓
碰到非 0
→ 放进新列表

同时记录：
→ 一共遇到了几个 0

最后
→ 往新列表后面补对应数量的 0
```

def move_zeroes(nums):

    new_nums=[]

    count=0

    for num in nums:

        if num!=0:

            new_nums.append(num)

        else:

            count+=1

    for i in range(count):

        new_nums.append(0)

    return new_nums

  

print(move_zeroes([0, 1, 0, 3, 12]))

print(move_zeroes([0, 0, 0, 1]))

你原来的错误分别是：

- `new_nums.append[num]` 应该是 `new_nums.append(num)`，方法调用用 `()`
- `count` 没有提前定义，应该先 `count = 0`
- `count+` 不是完整语句，应该是 `count += 1`
- `else` 缩进要和 `if` 对齐
完美，充实的一天。
