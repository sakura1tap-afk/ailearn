# Python 列表查找与成员判断

> [!abstract] 本篇重点
> **`in` 判断是否存在；`index()` 返回首次出现位置，找不到会报错。**
>
> 前置知识：[[Python 列表|Python 列表]]、[[python if语句|Python if 条件分支]]
> 所属知识链：[[00 Python学习导航]] · [[01 Python知识图谱]]

要在列表中找到元素的索引，使用 `index()`。
以下示例用 `cities.index('Mumbai')` 获取 Mumbai 首次出现的索引：

```python
cities = ['New York', 'Beijing', 'Cairo', 'Mumbai', 'Mexico']

result = cities.index('Mumbai')
print(result)
```

输出：

```text
3
```

但是，如果你用函数试图查找列表中不存在的元素，会收到错误。`index()`
错误：

```text
ValueError: 'Osaka' is not in list
```

可以先用成员运算符 `in` 判断元素是否存在。

`value in items` 在元素存在时返回 `True`，否则返回 `False`。

调用 `index()` 之前，可以先用 `in` 检查元素是否存在：

```python
cities = ['New York', 'Beijing', 'Cairo', 'Mumbai', 'Mexico']
city = 'Osaka'

if city in cities:
    result = cities.index(city)
    print(f"The {city} has an index of {result}.")
else:
    print(f"{city} doesn't exist in the list.")
```

输出：

```text
Osaka doesn't exist in the list.
```

## 摘要

- 用 `in` 判断元素是否存在，用 `index()` 查找其首次出现的位置。
