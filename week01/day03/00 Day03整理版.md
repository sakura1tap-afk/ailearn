## 1. 元组 tuple

元组和列表都能保存多个值，但元组创建后不能修改元素。

```python
point = (10, 20)
name, age = ("Tom", 18)
```

常见用途：
- 保存固定结构的数据，例如 `(name, score)`。
- 函数一次返回多个值时，Python 实际上常把它们打包成元组。

```python
def get_user():
    return "Tom", 18

result = get_user()   # ("Tom", 18)
```

关联：[[Python元组]]、[[Python 中解包列表]]

## 2. 序列解包

```python
name, score = ("Alice", 95)
```

左右变量数量通常要和右侧元素数量一致。

交换变量：

```python
a, b = b, a
```

## 3. 列表切片

格式：

```python
nums[start:end:step]
```

常用写法：

```python
nums[:3]     # 前三个
nums[-3:]    # 后三个
nums[::-1]   # 倒序副本
```

注意：切片本身已经会产生结果，不需要再调用 `slice()`。

关联：[[Python 列表切片]]

## 4. 列表推导式 list comprehension

把“遍历 + 条件 + 生成结果”压缩成一个表达式：

```python
[result for item in iterable if condition]
```

例如筛选偶数并平方：

```python
squares = [num ** 2 for num in nums if num % 2 == 0]
```

先能熟练写普通 `for + if + append`，再用推导式简化。

关联：[[Python 列表解析]]

## 5. for 遍历与 enumerate

直接遍历值：

```python
for num in nums:
    print(num)
```

同时需要下标和值：

```python
for index, num in enumerate(nums):
    print(index, num)
```

如果只是要元素，不要为了拿下标强行写 `range(len(nums))`。

关联：[[For 循环]]

## 6. 可迭代对象与迭代器

列表、元组、字符串、集合、字典等都可以被 `for` 遍历，因此它们是可迭代对象。

`map()`、`filter()` 在 Python 3 中返回的是可迭代结果，不是现成的列表：

```python
filtered = filter(lambda x: x > 0, nums)
print(list(filtered))
```

同一个迭代器被完整消费后，再转换一次通常会得到空结果。

关联：[[Python 迭代]]

## 7. sort() 与 sorted()

### list.sort()

原地修改列表，返回 `None`：

```python
nums.sort()
nums.sort(reverse=True)
```

### sorted()

返回新的排序列表，不修改原数据：

```python
new_nums = sorted(nums)
```

自定义排序依据：

```python
students = [("Tom", 78), ("Alice", 95)]
result = sorted(students, key=lambda student: student[1], reverse=True)
```

`key=` 可以理解成：“排序时到底拿元素的哪个值来比较？”

关联：[[Python 排序列表]]、[[Python sorted]]

## 8. map()：转换每个元素

基础形式：

```python
map(fn, iterable)
```

```python
def square(x):
    return x ** 2

result = list(map(square, [1, 2, 3]))
```

等价的 lambda 写法：

```python
result = list(map(lambda x: x ** 2, [1, 2, 3]))
```

关联：[[Python map（） 函数转换列表元素]]

## 9. filter()：按条件保留元素

基础形式：

```python
filter(fn, iterable)
```

判断函数返回 `True` 的元素会被保留：

```python
def is_valid(score):
    return 0 <= score <= 100

result = list(filter(is_valid, scores))
```

lambda 写法：

```python
result = list(filter(lambda score: 0 <= score <= 100, scores))
```

关联：[[Python中筛选列表元素]]

## 10. reduce()：把多个值累积成一个值

`reduce()` 在 `functools` 中：

```python
from functools import reduce

result = reduce(lambda a, b: a + b, [1, 2, 3, 4])
```

过程近似：

```text
1 + 2 -> 3
3 + 3 -> 6
6 + 4 -> 10
```

初学阶段，普通循环往往更直观，不必强行使用 `reduce()`。

关联：[[Python的reduce（） 函数将列表简化为单一值]]

## 11. 查找元素

判断是否存在：

```python
x in nums
x not in nums
```

获取第一次出现的下标：

```python
nums.index(x)
```

如果 `x` 不存在，`index()` 会抛出 `ValueError`。

关联：[[查找列表中元素的索引]]
